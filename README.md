# 3-13-05_Quiz_CRUDtoFullStack

From a CRUD Program to a Full Stack Application
Based on Last Week's CRUD program,

You will build:

a web UI,
a backend API,
and a Database
This will extend your app's functionality from local usage on your machine to anyone with an internet connection.

Requirements
Github
Create a Public Repo that should contain a README.md file and 2 folders titled Frontend and Backend.
Frontend
Build a UI using either React or Plain HTML, CSS, & JS. Your app needs to allow a user to perform CRUD actions. Use a Form, Buttons, or some unique UI/UX.
React App
Plain HTML+CSS+JS
Backend
Using JavaScript or Python, build an API server that can support the UI with endpoints to fulfill at least 1 of each HTTP Method (GET, POST, PUT, DELETE).
Node.JS + Express
FastAPI
DB
Using your local PostgreSQL server, create at least 1 table that will store information for your app.
